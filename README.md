# CorsoSTA
Informatica per Scienze e Tecniche Ambientali - Unisalento.

In questo repository troverete le dispense e lucidi del corso. Si invita fortemente gli studenti a NON usare solo
questo materiale nel preparare l'esame, ma ad integrarlo con quanto disponibile tramite Web, WikiPedia, e tramite
l'uso di sistemi di intelligenza artificiale: Mistral AI, Claude AI, ChatGpt, Google Gemini, Copilot.

* Lezione 1 (04/03): Introduzione al Corso 
* Lezione 2 (06/03): Rappresentazione dell'Informazione
* Lezione 3 (11/03): Architettura dell'Elaboratore
